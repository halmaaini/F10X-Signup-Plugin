# AI Dubai Registration

A WordPress plugin for **aidubaiconference.com/2026** (Future 10X): visitors register on the site, get a confirmation email, receive updates and a personal QR code from the organiser, and can make a shareable "I'm attending" poster.

Status: planning. See [`decisions.md`](decisions.md) and [`delivery/02-task-ledger.md`](delivery/02-task-ledger.md).
